**LGPD Redaction Policy (BR-E2E-006 / MR-E2E-006):**

Redactor scope:
- **Headers to redact in HAR**: `Authorization`, `Cookie`, `apikey`, `x-api-key` → replace value with `<redacted>`
- **Body paths to redact** (routed-based): any request to `/stripe/*` → entire POST body → `<body-redacted>`
- **JWT/token patterns** to block from git: regex `eyJ[A-Za-z0-9_-]{20,}` (JWT), `sk_(live|test)_` (Stripe), `sbp_` (Supabase service role)
- **Auth state filesystem isolation**: `~/.claude/auth-states/login-mcorch-prod.json` (600 perms, gitignored)
- **Evidence directory**: `e2e-output/` in `.gitignore` root (never committed; local-only or S3 sync)

Pre-commit hook (`.git/hooks/pre-commit`): Currently **does not exist or is minimal** — needs extension per BR-E2E-006 to:
- Check `git diff --cached` for JWT/token patterns

**Telemetry & Observability (BR-E2E-011 / MR-E2E-011):**
- Scope: Emit to `infra_health_logs` when runs fail due to **infra** (not findings)
- Examples: "browser launch timeout", "auth state corrupt", "HAR write failed"
- Payload: `{ run_id, mode, failure_phase, error_message }`
- Distinction: "Found P0 issue" is NOT an infra failure — that's expected output; only genuine infra errors emit telemetry
