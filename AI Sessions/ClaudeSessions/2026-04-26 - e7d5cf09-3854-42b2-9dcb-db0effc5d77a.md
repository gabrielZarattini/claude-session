> 433	
> 434	Root cause: `useSimulation` subscribed to entire Zustand store + `agents`/`edges` in `useEffect` deps. Every `updateAgentStatus` call created new array refs → effect cleanup + new interval → cascade under React 18 concurrent mode → Maximum Update Depth Exceeded + WebGL context loss.
> 435	
> 436	| File | Bug | Fix |
> 437	|------|-----|-----|
> 438	| `useSimulation.ts` | `agents`/`edges` in `useEffect` deps — recreated interval on every store update | `getState()` inside interval — zero deps, single interval, always-fresh reads |
> 439	| `SquadHull.tsx` | `filter()` inline selector — new array ref on every store update, SquadHull re-rendered every 3s regardless of squad | `useShallow` — element-by-element comparison, only re-renders when squad agents change |
> 440	| `CrewGraph.tsx` | `SQUAD_META` inside `Scene` render body — recreated every render | Hoisted to module scope |
> 441	| `AgentEdge.tsx` | Glow `<points>` sharing mutable `Float32Array` without `needsUpdate` — GPU waste + potential context pressure | Removed broken element |
