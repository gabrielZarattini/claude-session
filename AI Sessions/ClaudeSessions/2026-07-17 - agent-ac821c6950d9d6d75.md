# firecrawl scrape

Scrape one or more URLs. Returns clean, LLM-optimized markdown. Multiple URLs are scraped concurrently.

## When to use

- You have a specific URL and want its content
- The page is static or JS-rendered (SPA)
- Step 2 in the [workflow escalation pattern](firecrawl-cli): search → **scrape** → map → crawl → interact

## Quick start

```bash
# Basic markdown extraction
firecrawl scrape "<url>" -o .firecrawl/page.md

# Main content only, no nav/footer
firecrawl scrape "<url>" --only-main-content -o .firecrawl/page.md

# Wait for JS to render, then scrape
firecrawl scrape "<url>" --wait-for 3000 -o .firecrawl/page.md

# Multiple URLs (each saved to .firecrawl/)
firecrawl scrape https://example.com https://example.com/blog https://example.com/docs

# Get markdown and links together
firecrawl scrape "<url>" --format markdown,links -o .firecrawl/page.json

# Ask a question about the page
firecrawl scrape "https://example.com/pricing" --query "What is the enterprise plan price?"
```

## Options

| Option                   | Description                                                      |
| ------------------------ | ---------------------------------------------------------------- |
| `-f, --format <formats>` | Output formats: markdown, html, rawHtml, links, screenshot, json |
| `-Q, --query <prompt>`   | Ask a question about the page content (5 credits)                |
| `-H`                     | Include HTTP headers in output                                   |
| `--only-main-content`    | Strip nav, footer, sidebar — main content only                   |
| `--wait-for <ms>`        | Wait for JS rendering before scraping                            |
| `--include-tags <tags>`  | Only include these HTML tags                                     |
| `--exclude-tags <tags>`  | Exclude these HTML tags                                          |
| `-o, --output <path>`    | Output file path                                                 |

## Tips

- **Prefer plain scrape over `--query`.** Scrape to a file, then use `grep`, `head`, or read the markdown directly — you can search and reason over the full content yourself. Use `--query` only when you want a single targeted answer without saving the page (costs 5 extra credits).
- **Try scrape before interact.** Scrape handles static pages and JS-rendered SPAs. Only escalate to `interact` when you need interaction (clicks, form fills, pagination).
- Multiple URLs are scraped concurrently — check `firecrawl --status` for your concurrency limit.
- Single format outputs raw content. Multiple formats (e.g., `--format markdown,links`) output JSON.
- Always quote URLs — shell interprets `?` and `&` as special characters.
- Naming convention: `.firecrawl/{site}-{path}.md`

## See also

- [firecrawl-search](../firecrawl-search/SKILL.md) — find pages when you don't have a URL
- [firecrawl-interact](../firecrawl-interact/SKILL.md) — when scrape can't get the content, use `interact` to click, fill forms, etc.
- [firecrawl-download](../firecrawl-download/SKILL.md) — bulk download an entire site to local files

| Acesso não-autorizado (CFAA/EUA) | Estatutário | **bypass de login/auth**, conta falsa | [hiQ v LinkedIn](https://en.wikipedia.org/wiki/HiQ_Labs_v._LinkedIn) |
| Infração de copyright | Estatutário | **redistribuir o vídeo original** ou porção substancial | [17 USC 107](https://www.law.cornell.edu/uscode/text/17/107) (fair use é defesa, não licença) |
| TDM sem respeitar opt-out (UE) | Estatutário | minerar obra com reserva de direitos | [Art. 4(3) Dir. 2019/790](https://knowledgerights21.org/news-story/eu-tdm-exceptions-can-be-used-for-ai/) |
| Sanção LGPD (até 2% fat., teto R$ 50M/infração) | Administrativo | tratar dado pessoal de 3º sem base/princípios | [Art. 52 LGPD](https://lgpd-brasil.info/capitulo_08/artigo_52) |
| Não-marcação de output IA (UE, a partir 02/08/2026) | Administrativo | não marcar mídia sintética gerada | [AI Act Art. 50](https://artificialintelligenceact.eu/article/50/) |

### Mitigações concretas (todas ancoradas)
1. **NUNCA redistribuir o vídeo original** — reter apenas a análise/estratégia derivada (uso transformativo, fator 4 do fair use neutralizado — [17 USC 107](https://www.law.cornell.edu/uscode/text/17/107)).
2. **Nunca contornar login-wall/CAPTCHA/auth** — é a linha CFAA (ilegalidade), não mera quebra de ToS — [hiQ](https://en.wikipedia.org/wiki/HiQ_Labs_v._LinkedIn). Processar **só conteúdo público**.
3. **Respeitar robots.txt e reservas de direitos (`noai`/TDM-reservation)** — dupla função: exceção contratual do próprio YouTube ([ToS](https://www.youtube.com/static?template=terms)) **e** condição da exceção legal de TDM na UE ([Art. 4(3)](https://knowledgerights21.org/news-story/eu-tdm-exceptions-can-be-used-for-ai/)).
4. **Preferir APIs oficiais** onde existirem (única via "com permissão" prevista nos ToS de todas as 3).
5. **Retenção mínima: deletar o mp4 baixado em ≤30 dias, manter só a análise** — ancorado no princípio de **necessidade** da LGPD (Art. 6) e minimização; reduz superfície de dado pessoal retido.
6. **LGPD:** apoiar tratamento em legítimo interesse (Art. 7 IX) + dado manifestamente público (Art. 7 §4), com LIA documentada; tratar rosto/voz como potencialmente sensível (Art. 11); **não** confiar na isenção do Art. 4 (SaaS comercial não é uso pessoal/jornalístico).
7. **AI Act:** manter **controle editorial humano** sobre o roadmap (isenção do Art. 50(4)) e **marcar mídia sintética gerada** (Art. 50(2)) — já coberto pela stack de provenance IPTC existente. Vigência a preparar: **02/08/2026** ([Art. 50](https://artificialintelligenceact.eu/article/50/)).
