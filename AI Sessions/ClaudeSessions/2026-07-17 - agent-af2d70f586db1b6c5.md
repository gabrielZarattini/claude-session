> 128	## 4. Marking Design — 3 camadas × 3 modalidades (o coração da solução)
> 129	
> 130	### 4.1 Roteamento (Pattern #2 Routing — por modalidade × origem)
> 131	
> 132	```
> 133	routeLayers(kind, origin):
> 134	  IF origin == 'signed'          → PRESERVE-AND-ATTACH (FR-CP-004): detect → attach assertion, no blind re-encode
> 135	  kind == 'image'                → [C1 c2patool, C2 TrustMark,  C3 ExifTool]
> 136	  kind == 'video'                → [C1 c2patool, C2 VideoSeal,  C3 ExifTool]   # VideoSeal compute-gated (OTD-CP-009)
> 137	  kind == 'audio' (voz)          → [C1 c2patool, C2 AudioSeal]                 # C3 IMPOSSÍVEL — IPTC não cobre áudio (OTD-CP-007)
> 138	```
> 139	
> 140	### 4.2 Cadeia de embed (Pattern #1 Prompt Chaining — determinística, não-LLM)
> 141	
> 142	```
> 143	IMAGEM (Nano Banana / gemini-2.5-flash-image via generate-image / canvas-execute)
> 144	  ├─ [origin=signed] PRESERVAR C2PA+SynthID de origem — ⚠️ cobertura de gemini-2.5-flash-image NÃO confirmada (OTD-CP-004/§10.1)
> 145	  ├─ C1  c2patool: manifesto (claim_generator='MCORCH', c2pa.actions=created, digitalSourceType=<enum>)
> 146	  ├─ C2  TrustMark: watermark ~100-bit, soft-binding C2PA nativo (casa C1↔C2), payload = creative_assets.id
> 147	  └─ C3  ExifTool: XMP-iptcExt:DigitalSourceType = <URI IPTC>
> 148	
> 149	VÍDEO (HyperFrames determinístico via video-bridge + Veo via veo-poll)
> 150	  ├─ Veo → SynthID de origem provável (preservar, bônus); HyperFrames → SEM SynthID (C2 obrigatório)
> 151	  ├─ C1  c2patool: manifesto no MP4/MOV (c2pa-rs embeda MP4/MOV/AVI)
> 152	  ├─ C2  VideoSeal: watermark temporal, payload uuid opaco ⚠️ compute (OTD-CP-009)
> 153	  └─ C3  ExifTool: XMP DigitalSourceType (⚠️ placement QuickTime — provar sobrevivência ao roundtrip, OTD-CP-008)
> 154	
> 155	VOZ (clone Qwen3-TTS via voice-bridge)
> 156	  ├─ C1  c2patool: manifesto em WAV/MP3/M4A/FLAC
> 157	  ├─ C2  AudioSeal: watermark localizado de fala, robusto a compressão/re-encode, payload uuid opaco
> 158	  └─ C3  ✗ LACUNA declarada — IPTC não cobre áudio ⇒ layers={c2pa,watermark} (OTD-CP-007/FM-CP-06)
> 159	```
> 160	
> 161	### 4.3 Vocabulário IPTC honesto (Pattern #18 Guardrail — FR-CP-010/G5)
> 162	
> 163	- Conteúdo **100% gerado** ⇒ `digitalSourceType = trainedAlgorithmicMedia` ("Created using Generative AI").
> 164	- Asset **AI-editado** (reframe/inpaint/outpaint via `reshape-pillar`) ⇒ `compositeWithTrainedAlgorithmicMedia` ("Edited using Generative AI") — https://cv.iptc.org/newscodes/digitalsourcetype/.
> 165	- Regra materializada como **enum** (Fatia 0, seed do SKOS IPTC); marcar edição como geração é **rejeitado pela regra** (FM-CP-12).
> 166	- As 3 camadas compartilham o **mesmo** vocabulário IPTC — C2PA incorpora-o na IPTC assertion (https://c2pa.org/digitalsourcetype/trainedalgorithmicdata/) — reduz inconsistência de rótulo (§3.5 blueprint).
> 167	
> 168	### 4.4 Payload do watermark (invariante de privacidade — FR-CP-008/DG-7)
> 169	
> 170	Valor gravado = `creative_assets.id` (uuid opaco). TrustMark ~70 bits protegidos / VideoSeal 256-1024b / AudioSeal — capacidade sobra p/ um uuid. **Proibido** `user_id`, email, nome de tenant, `project_id` legível. `smoke-provenance-pii-reject.ts` **falha o build** se qualquer PII entra no payload (G6/OTD-CP-013/FM-CP-05).
