## Analysis of X/Twitter gone-detection (the core concern)

**X DELETE `/2/tweets/{id}` real API behavior:**

- Deleting a tweet you don't own / forbidden: HTTP **403** — X v2 returns `{"errors":[{...}],"title":"Forbidden",...}` or a problem-details body.
