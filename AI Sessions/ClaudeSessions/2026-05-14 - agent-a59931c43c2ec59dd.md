### 6. PROCESS FLOWS

#### **A. Trend Mining Journey**
1. User navigates to `/dashboard/miner`
2. Select platform + niche + min score, optionally search
3. Click "Mine Trends" → call `useFetchTrends().mutate()`
4. Edge function `fetch-trends` calls Apify / RapidAPI / falls back to cache
5. Trends upserted to vm_trends (external_id as conflict key)
6. Results hydrate vm_trends query
7. User browses trend cards (viral_score, velocity, hashtags)
8. Click "Save" → `useSaveTrend().mutate()` → upsert vm_user_trends (is_favorite=true)
9. (TODO) Click "Create" → navigate to Canvas Studio with trend as context

#### **B. Canvas Studio Journey**
1. User navigates to `/dashboard/canvas` → CanvasStudioPage
2. See list of own vm_canvas_projects
3. Click "New Project" → dialog, input name+desc → `useCreateCanvasProject()`
4. Inserted to vm_canvas_projects, navigate to editor `/dashboard/canvas/{id}`
5. CanvasEditorPage loads project from vm_canvas_projects
6. Initialize useCanvasStore with graph + viewport
7. LeftPanel shows recipes (CANVAS_RECIPES), assets (vm_canvas_assets), trends (vm_trends), history (vm_canvas_executions)
8. User drops nodes from recipes / adds manually
9. Select node → RightPanel: configure provider/model/prompt
10. Click "Executar nó" → `useCanvasExecute().mutate()`
    - Canvas-execute edge function routes to provider (OpenAI, Replicate, etc.)
    - Polls for completion
    - Stores output in vm_canvas_assets + Supabase Storage
    - Deducts mcoCoins via deduct_mco_coins RPC
    - Updates vm_canvas_executions
    - Populates node outputUrl in store
11. useAutoSave flushes graph to vm_canvas_projects every 60s
12. Run-all: sequentially execute all nodes with prompts
13. Export (Phase 4.2): compile outputs to video

#### **C. Credit Deduction Flow**
1. Node execution triggered
2. canvas-execute calculates credit cost (CREDIT_COSTS map)
3. Check profiles.mco_balance >= cost (402 if insufficient)
4. Create vm_canvas_executions record (status=running)
5. After provider success:
   - Create vm_canvas_assets record
   - Call deduct_mco_coins(user_id, cost)
   - RPC updates profiles.mco_balance
6. Return credits_remaining in response
