  ```js
  vf += `,drawtext=textfile='${capPath}':fontfile=${FONT}:fontsize=${fontsize}:fontcolor=white:` +

  ```
  Note the **byte-vs-char padding hack** (lines 74–79): this FFmpeg build's `drawtext(textfile)` truncates rendered text by the number of *extra* UTF-8 bytes, clipping accented tails (e.g. `notícia.`→`notíc`); they pad with trailing spaces so truncation eats the padding. Bottom-center, translucent black box. Font is hardcoded `DejaVuSans-Bold.ttf` (line 21). One textfile per clip (`cap_<index>.txt`).
