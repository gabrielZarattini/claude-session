## 1. Scope Statement

`content-intel` é o **sensor de entrada** do ecossistema: o usuário cola o link de um vídeo que **já existe** (YouTube / Instagram / TikTok), o sistema **resolve → analisa server-side via Vision MCP (Gemini) → modela uma estratégia/roadmap textual persistente** (gancho dos 3s, tema, personagens, formato, CTA, tom, marca) e **alimenta o motor de geração que já existe** (canvas-execute / reshaper / autopilot), fechando o flywheel **estudar → modelar → GERAR → PUBLICAR → MEDIR**.

**In scope**

- Edge fn **NOVA** `content-intel-run` (orquestrador in-app com gate mcoCoins) — o content-intel "feito à mão" hoje só existe como slash-command `competitive-vision.md`.
- **Caminho YouTube** — URL direto ao Gemini via Vision MCP, **zero download** (§3a — o download acontece do lado do Google).
- **Caminho IG/TikTok** — resolução de mp4 **gated por OTD-CI-002** (bloqueio de IP de datacenter Oracle — sondar antes de assumir; **NÃO afirmar taxa de sucesso %**).
- **Cache de mídia EFÊMERO e ISOLADO** (bucket próprio, retenção 30d) + **`content_strategy` PERSISTENTE** (nunca expira) como fonte da verdade (§5/OTD-CI-001/005).
- Reuso (não reconstrução): `vision_analyze_video` via `mcp.mcorch.com`, `deduct_mco_coins`, `resolveProviderKey`, `mcorch_nodes`+auto-embed, buckets privados owner-scoped, retention-sweep 30d.
- Métrica por-vídeo **só via API oficial** (YouTube Data v3) — nunca do Gemini (§3/OTD-CI-003).
- UI/Hook em `/dashboard` + loop de "gerar a partir da estratégia".
- Guardrails de nicho sensível + marcação de proveniência **na saída de geração** (§9).

**Out of scope**

- Reconstrução de análise de mídia, persistência/cobrança/embedding/credencial (tudo reusado).
- Ingest **server-side** de IG/TikTok a partir do host Oracle **antes** de fechar OTD-CI-002 (nasceria morto — classe do 501 YouTube / WordPress CF AS31898).
- Persistir vídeo de terceiro na **spine `creative_assets`** (FM-CI-01 — contamina proveniência AI Act; a spine serve só derivados **OWNED**).
- Métrica de performance por-vídeo para **TikTok** (sem caminho oficial comercial) e **IG de conta não-profissional** (OTD-CI-003, decisão Sovereign).
- Qualquer ingest atrás de login-wall/CAPTCHA/conta-falsa (linha CFAA — FM-CI-09).
- Parecer jurídico (é levantamento factual; o GO exige revisão jurídica humana).
