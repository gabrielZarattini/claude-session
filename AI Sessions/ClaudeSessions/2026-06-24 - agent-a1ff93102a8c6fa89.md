> 88	
> 89	```
> 90	[Component: AutopilotPage.tsx]

> 95	  ↓ dispatch (service-role + x-autopilot-user-id server-trusted + prepaid=true)
> 96	[Edge Function: orchestrate-content → orchestrate-step]   (geração product-aware + monetize; prepaid → NÃO self-bill)

> 101	### 4.2 External API Contracts
> 102	
> 103	#### `POST /functions/v1/autopilot-run`
> 104	
> 105	**Auth:** Bearer JWT (user scope, "gerar agora" — asserir `user.id === plan.user_id`) — OU caminho cron: **a fn prova service-role in-function** (`Authorization === 'Bearer '+SB_SECRET_KEY`, padrão `orchestrate-step:50-53`) ANTES de confiar no header `x-autopilot-user-id` (`user_id` server-trusted de `autopilot_plans.user_id`, **nunca do body**; `verify_jwt=false`). SOP `edge-jwt-identity-verification.md`.  
> 106	**Request:**
> 107	```typescript
> 108	{
> 109	  plan_id: string,          // uuid do autopilot_plans (RLS-own)
> 110	  mode_override?: "all_at_once" | "every_n_days",  // opcional; default = plano
> 111	  dry_run?: boolean,        // se true, retorna custo projetado SEM deduzir nem publicar
> 112	}
> 113	```
> 114	**Response (200):**
> 115	```typescript
> 116	{
> 117	  status: "ok",
> 118	  cycle_id: string,
> 119	  cycle_number: number,
> 120	  projected_cost_mco: number,
> 121	  dispatched: { product_id: string, platform: string, run_id: string }[],
> 122	}
> 123	```
> 124	**Error codes:**
> 125	| Code | Condition |
> 126	|------|-----------|
> 127	| 401 | JWT ausente/inválido |
> 128	| 402 | Saldo de mcoCoins insuficiente (`insufficient_balance`) |
> 129	| 409 | Teto **por ciclo** excedido — body `{ reason: "aborted_budget" }` — plano pausado |
> 130	| 409 | Cap **diário** global do tenant excedido (FR-VA-021) — body `{ reason: "aborted_daily_cap" }` |
> 131	| 422 | Validação: plano sem produtos/redes, `interval_days` inválido (campo+mensagem PT-BR) |
> 132	| 500 | Erro interno (logado em `infra_health_logs`) |
> 133	
> 134	#### `POST /functions/v1/autopilot-analyze`
> 135	
> 136	**Auth:** service-role (`verify_jwt=false`); invocada inline pós-ciclo pelo `autopilot-cadence-cron`.  
> 137	**Request:** `{ previous_cycle_id: string }` — **`tenant_id`/`plan_id` NÃO vêm do body** (anti-IDOR, STRIDE §5.1). São **derivados**: `SELECT user_id, plan_id FROM autopilot_cycles WHERE id = previous_cycle_id` (service-role).  
> 138	**Response (200):** `{ status: "ok", optimization_policy_id: string, has_real_data: boolean, top_features: {...} }`  
> 139	> `has_real_data=false` quando `creative_metrics` do ciclo anterior está vazia → usa baseline, NÃO inventa, **NÃO cobra** (log `analyze_empty`). Quando `true`: deduz `ANALYZE_COST(2)` via `deduct_mco_coins(user_id_derivado, 2)`.
