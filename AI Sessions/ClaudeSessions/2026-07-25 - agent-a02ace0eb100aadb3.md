### 2. Quebra / degrada / OK — **OK, o fallback Storage cobre**
A prova está no **enqueuer**, `supabase/functions/generate-subtitles/index.ts`, que popula `composition.source_bucket` **em tempo de enfileiramento, lendo o `creative_assets` atual owner-scoped** — nunca um path do cliente:

```
.select("storage_bucket, storage_key, kind").eq("id", sourceAssetId).eq("user_id", userId)
const bucket = String(asset.storage_bucket);   // ← valor CORRENTE da linha
composition: { ... source_bucket: bucket, source_key: key, ... }
```

Como a migração W2.1 repontou os `creative_assets` de EP01/EP02 de `storage_bucket='local'` → `'video-studio-assets'`, **todo job novo de transcrição já nasce com `source_bucket='video-studio-assets'`** → cai no branch Storage (`subtitle-bridge.ts:125-130`) → baixa da Storage, onde o arquivo AGORA existe. O branch `local` (`:120-124`) simplesmente fica dormente; não há caminho vivo apontando para o disco deletado.

Não há acoplamento cego ao host: o worker não faz `find`, não assume `INBOX_BASE`, e só entra no branch host quando a composição diz `'local'` — o que o enqueuer não emite mais para esses masters.

### 3. Severidade: **OK**
Duas notas materiais, nenhuma é break vivo:
- **P2 (eficiência, inerente à migração, não desta superfície):** o branch Storage baixa o master INTEIRO para `workDir` (`:126-129`) antes do ffmpeg — para um master de 1.3 GB é download+disco cheios a cada job, vs a leitura zero-copy do disco que o branch `local` fazia. Correto funcionalmente, mais caro. Consequência esperada de mover 1.3 GB para a Storage.
- **Latente benigno:** qualquer `video_renders` **pré-migração** ainda `state='queued'` com `composition.source_bucket='local'` apontando para o path deletado falharia limpo em `local_source_not_found` (`:123`) → `finalize(...,'failed')` (`:203`), sem travar a fila (o reaper `:179-187` cobre 'running' preso). É um fail-open, não um crash.

### 4. Fix
Nenhum fix obrigatório — a superfície está coberta pelo fallback Storage e pelo enqueuer que já lê o `storage_bucket` corrente. Opcional, se quiser eliminar o risco latente: um one-shot para requeue/failar `video_renders` órfãos `engine='asr' AND state='queued' AND composition->>'source_bucket'='local'`. Não é bloqueante.
