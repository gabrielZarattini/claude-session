> ### 1.1 Fluxo OAuth 2.0 — Installed / Desktop app (verificado)
> 
> Fonte: `youtube/v3/guides/auth/installed-apps`.
> 
> 1. **PKCE:** gerar `code_verifier` (43–128 chars) → `code_challenge` via **S256** (SHA-256, recomendado) ou `plain`.
> 2. **Authorization request:** `GET https://accounts.google.com/o/oauth2/v2/auth` com `client_id`, `redirect_uri`, `response_type=code`, `scope` (space-delimited), `code_challenge`+`code_challenge_method`, `state` (CSRF, recomendado).
>    - **Custom URI schemes descontinuados** (risco de impersonação em Android/Chrome). Usar **loopback IP** `http://127.0.0.1:port` ou `http://[::1]:port` para desktop.
> 3. **Consent:** Google mostra nome do app + serviços solicitados.
> 4. **Response:** authorization code (ou erro) no redirect.
> 5. **Token exchange:** `POST https://oauth2.googleapis.com/token` com `client_id`, `client_secret` (opcional p/ installed), `code`, `code_verifier`, `grant_type=authorization_code`, `redirect_uri`. Header `DPoP` opcional. Retorna `access_token`, `refresh_token`, `expires_in`, `scope`.
> 6. **Verificar escopos concedidos:** inspecionar campo `scope` — "usuários podem não conceder todos".
> 7. **Refresh:** `POST https://oauth2.googleapis.com/token` com `grant_type=refresh_token` + `refresh_token`. Access token expira; refresh token vale até revogado.
> 8. **Chamada de API:** header `Authorization: Bearer <access_token>` (preferido) ou `?access_token=`.
> 9. **Revogação:** `https://oauth2.googleapis.com/revoke?token={token}` → HTTP 200 ok / 400 erro.
> 
> > **Nota de segurança oficial:** apps instalados NÃO guardam segredos com segurança → **PKCE obrigatório**; DPoP recomendado; refresh tokens em storage seguro; escopos sensíveis exigem verificação p/ remover aviso "unverified app".
