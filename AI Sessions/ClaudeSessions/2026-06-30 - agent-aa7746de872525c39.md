> 351	### 5.1 Threat Model (STRIDE por componente)
> 352	
> 353	| Component | Threat | STRIDE Type | Severity | Mitigation |

> 356	| `avatar_identities` / `voice_profiles` | Leitura cross-tenant de PII biométrica (weights/voiceprint de outro tenant) | Information Disclosure | **Critical** | RLS own `auth.uid() = user_id` default-deny; FMEA-011; storage prefixo `user_id/` + signed URL curta (NFR-AC-013) |

```sql
  p_avatar_identity_id uuid DEFAULT NULL,
  p_voice_profile_id   uuid DEFAULT NULL
)
RETURNS jsonb
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = ''
AS $$
DECLARE
  v_user_id uuid := auth.uid();              -- service_role passes user via row-scope (not body — OTD-VA-008)
  v_storage_keys text[] := '{}';
  v_key text;
BEGIN
  -- Tenant guard: each DELETE re-scoped by user_id (poisoned id NOT a cross-tenant primitive — FM-AC-011).
  IF p_avatar_identity_id IS NOT NULL THEN
    SELECT identity_storage_key INTO v_key FROM public.avatar_identities
      WHERE id = p_avatar_identity_id AND (user_id = v_user_id OR auth.role() = 'service_role');
    IF NOT FOUND THEN RAISE EXCEPTION 'avatar_identity_not_found' USING errcode = 'P0002'; END IF;
    v_storage_keys := array_append(v_storage_keys, v_key);
    DELETE FROM public.avatar_identities WHERE id = p_avatar_identity_id
      AND (user_id = v_user_id OR auth.role() = 'service_role');     -- embedding + mesh node deletes together
  END IF;
  IF p_voice_profile_id IS NOT NULL THEN
    DELETE FROM public.voice_profiles WHERE id = p_voice_profile_id
      AND (user_id = v_user_id OR auth.role() = 'service_role');     -- voiceprint Vault revoked by edge fn
  END IF;
  -- Storage objects NOT deleted here (storage.objects = storage-admin role; SECURITY DEFINER gets 42501).
  -- Caller (erase-avatar-artifacts edge fn / retention-sweep, service-role) removes via Storage API + revokes
  -- Vault secrets + dispatches delete to 3rd-party APIs (Art. 18) — best-effort + reconcile (OTD-VM-026 lesson).
  RETURN jsonb_build_object('erased', true, 'storage_keys', to_jsonb(v_storage_keys));
END $$;

REVOKE EXECUTE ON FUNCTION public.erase_avatar_artifacts(uuid, uuid) FROM PUBLIC, anon;
GRANT  EXECUTE ON FUNCTION public.erase_avatar_artifacts(uuid, uuid) TO authenticated, service_role;
```

**Key Contract Points:**
- **SECURITY DEFINER:** owned by migration role, bypasses RLS for cascade delete.
- **Tenant guard:** **every** DELETE re-scoped by `user_id = v_artifact.user_id` to prevent poisoned IDs from becoming cross-tenant deletion primitives (FM-AC-011).
- **Storage-API caveat (OTD-VM-026 lesson):** Storage objects (`storage.objects` table) are owned by the `storage-admin` role. - **EXECUTE grants:** revoked from PUBLIC/anon; granted to authenticated (self-scoped) + service_role (for sweep).
