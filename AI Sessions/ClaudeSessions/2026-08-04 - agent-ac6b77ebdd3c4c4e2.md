Ciclo de vida da mensagem (runtime normativo)\n\n1. Cliente envia `{thread_id, client_msg_id, content}` via SSE POST (JWT).\n2. Edge fn: sentinel no input (FR-SA-037) \u2192 recusa estruturada se hostil.\n3. `begin_agent_message(p_user_id, p_thread_id, p_client_msg_id, p_amount=1, p_context)` \u2014\n   insere mensagem user + placeholder assistant `status='streaming'` + debita 1 mco na MESMA tx.\n   Duplicata de `client_msg_id` \u2192 retorna a existente, **nunca re-debita** (FR-SA-004).\n4.
